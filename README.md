# 🚦 Road Accident Dashboard (Excel)

## Project Overview
This project analyzes road accident data using Microsoft Excel to identify accident patterns, severity levels, and high-risk conditions. An interactive dashboard is created to present accident casualty insights in a clear and visual format.

## Objectives
The main objective of this project is to analyze road accident casualties over time, understand accident severity (Fatal, Serious, Slight), and study the impact of road type, light conditions, and location on accidents.

## Dataset Description
The dataset contains road accident records with fields such as accident date, year, month, accident severity, vehicle type, road type, road surface condition, light condition, urban or rural area, and number of casualties.

## Data Processing
The data was imported into Excel and analyzed using existing year and month columns. Pivot Tables were created to summarize casualties by severity, road conditions, location, and time. Slicers were applied to enable interactive filtering.

## Dashboard Components
The dashboard includes KPI cards for total, fatal, serious, and slight casualties, monthly trend comparison (CY vs PY), and charts showing casualties by road type, road surface, light condition, and urban/rural area.

## Key Insights
Most road accident casualties occur on single carriageways. Urban areas record higher casualties compared to rural areas. A majority of accidents occur during daylight conditions, and cars are the most involved vehicle type in road accidents.

## Recommendations
Improve safety measures on single carriageways, strengthen traffic management in urban areas, promote safety awareness for car drivers, and monitor accident trends regularly to support accident prevention planning.
